# HealthTracker UI/UX Design

Jira Issue: HL6-5

## Main screens
1. Dashboard — overview and shortcuts to key actions.
2. Log Health Data — form to enter and validate health records.
3. History — list of previously saved health records.
4. Profile — basic user preferences and account information.

## Navigation
Use a consistent navigation menu to move between Dashboard, Log Health Data, History, and Profile.

## Usability
- Use clear headings and readable labels.
- Keep data-entry forms simple.
- Show confirmation after saving a record.
- Display understandable validation and error messages.
- Keep the layout consistent across screens.

## Acceptance criteria
- The four main screens are documented.
- Navigation between screens is defined.
- Core data-entry and error states are considered.
- The design notes are available for review.
