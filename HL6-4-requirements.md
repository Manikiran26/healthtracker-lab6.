# HealthTracker App — Requirements

**Jira Issue:** HL6-4  
**Work item:** Requirements Gathering  
**Project:** HealthTracker Lab 6

## 1. Objective

Define the minimum requirements for a HealthTracker application that helps users record and review their health-related information.

## 2. Functional Requirements

- Users should be able to access the application's main dashboard.
- Users should be able to enter and save health-related records.
- Users should be able to view previously saved records.
- Users should be able to navigate between the main application screens.
- The application should provide clear feedback when a record is saved or when an error occurs.

## 3. Non-Functional Requirements

- The interface should be simple and understandable.
- Input fields should validate required information.
- Health-related records should not be exposed to unauthorized users.
- The application should provide understandable error messages.
- The design should support future enhancements.

## 4. Acceptance Criteria

- The initial functional and non-functional requirements are documented.
- The proposed minimum viable product (MVP) scope is identified.
- Requirements are available for review by the project team.
- The requirements document is stored in the repository and linked to Jira issue HL6-4.

## 5. Initial MVP Scope

The initial scope covers the dashboard, recording health data, reviewing saved records, and basic navigation. Additional features can be considered after the core requirements are reviewed.HL6-4-requirements.md
